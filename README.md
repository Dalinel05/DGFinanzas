
# Gestor de Gastos Personales

## Descripción
Aplicación para administrar ingresos y gastos
personales, consultar movimientos y visualizar
el saldo disponible.

## Tecnologías
- Python
- SQL Server
- FastAPI
- Git y GitHub

## Funcionalidades principales
- Registrar ingresos.
- Registrar gastos.
- Consultar movimientos.
- Calcular el saldo disponible.
- Administrar categorías.
